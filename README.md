# andreyka — авторские работы

Личное портфолио Андрея: дизайн, игровые проекты CityCore и Minecraft Royale, цифровой архив Дома Мироновых. На титульном экране — имя и античная скульптура; ниже — знакомство с автором, кликабельный коллаж и раздел разработки. Сайт работает без CDN и установки пакетов.

## Запуск и сборка

Нужен Node.js 22 или новее.

```sh
npm run dev
```

Локальный адрес: http://localhost:5173.

```sh
npm run check
npm run build
npm run preview
```

Для размещения на статическом хостинге используйте содержимое `dist/`. Пути относительные, поддерживается размещение в подпапке. Локальный сервер поддерживает HTTP Range для перемотки видео. Загрузка исходников в GitHub сама по себе не включает хостинг.

## Структура

- `index.html` — титульный экран, раздел об авторе, дизайн, разработка, контакты и модальные окна.
- `content.js` — четыре альбома, 20 изображений и подробные описания проектов.
- `app.js` — галереи, видео, навигация, копирование почты и анимации.
- `styles.css` — оформление, шрифты, адаптивность и уменьшение движения.
- `assets/` — изображения, оригиналы музейных фотографий, два видео и лицензии шрифтов.
- `scripts/` — сервер, проверка, сборка и обработка музейных вырезок.
- `glass.js` — сохранённая реализация оптического стекла; в текущей странице не подключена.

Коллаж «Opera mea» открывает большое окно со всеми альбомами, включая «Другие работы». Изображения открываются в отдельном окне с увеличением, миниатюрами, стрелками и скачиванием. Закрытие вложенного окна возвращает фокус в коллекцию. Видео запускаются по нажатию и останавливаются при закрытии.

Анимации сбрасываются при полном выходе элементов из области просмотра и повторяются при возвращении. Новые элементы можно подключать через `data-motion="title"`, `"image"`, `"rise"` или `"type"`. Эффект набора открывает исходный текст маской, сохраняя межбуквенные интервалы и переносы. Все эффекты учитывают `prefers-reduced-motion`.

## Шрифты

Jun и Bounded подключены из переданных файлов; лицензии сохранены в `assets/fonts/`. SF Pro доступен только в локальной версии из папки `fonts/` или как установленный системный шрифт. Папка `fonts/` исключена из Git. Сборка исключает файлы SF Pro и ссылки на них: на Apple используется системный шрифт, на остальных устройствах — Bounded.

## Происхождение изображений

Дизайн-работы взяты из авторских экспортов Figma. Изображения и видео Дома Мироновых — из [репозитория цифрового архива](https://github.com/sasasamorez-eng/pryanichnyy_domik_17_Standoff2). Файл `house-night.webp` содержит дневной снимок; имя сохранено из источника.

Музейные фотографии Met Open Access находятся в общественном достоянии. Оригиналы сохранены в `assets/`:

- [Голова греческого полководца, 251493](https://www.metmuseum.org/art/collection/search/251493) — титульная скульптура.
- [Статуя атлета, 255120](https://www.metmuseum.org/art/collection/search/255120) — сохранена среди исходников.
- [Зевс, 252511](https://www.metmuseum.org/art/collection/search/252511) — сохранённая музейная фотография.
- [Афина, 258077](https://www.metmuseum.org/art/collection/search/258077) — первая голова в декоративном блоке.
- [Римский портрет, 249050](https://www.metmuseum.org/art/collection/search/249050) и [портрет с бородой, 255693](https://www.metmuseum.org/art/collection/search/255693) — сохранённые прежние изображения.
- [Аполлон, 255057](https://www.metmuseum.org/art/collection/search/255057) и [богиня, 256431](https://www.metmuseum.org/art/collection/search/256431) — две новые головы в декоративном блоке.
- Платон и Аристотель — из оригинала [«Афинской школы» Рафаэля](https://commons.wikimedia.org/wiki/File:%22The_School_of_Athens%22_by_Raffaello_Sanzio_da_Urbino.jpg), Public Domain.

Ранее подготовленные `sculpture-general-cutout.webp`, `sculpture-zeus-cutout.webp`, `met-athena-cutout.png` и прежние портретные вырезки обрабатывались imagegen: возможны отличия деталей от оригиналов. Новые Аполлон, богиня, Платон и Аристотель вырезаны из готовых оригиналов без генерации. Для пересоздания новых вырезок сначала запускайте `scripts/cut-antique.py`, затем `scripts/refine-philosophers.py` (Python, Pillow, NumPy).

## Проверка

`npm run check` проверяет JavaScript, локальные изображения, уникальность HTML ID и ссылки на разделы. Текущая версия дополнительно проверена в Edge на компьютере и телефоне: все альбомы, вложенные окна, Escape, возврат фокуса, блокировка прокрутки, уменьшенное движение и отсутствие горизонтального переполнения. Локальные снимки и сценарии находятся в исключённой из Git папке `.qa/`.
